# eSend

把 iPhone 截图发到电脑白板。在手机上截屏，轻点两下背面，图片就会出现在浏览器里。你可以拖动、缩放，也可以选中多张图，拼成一张 PNG 复制。

手机和电脑通过同一个 Wi-Fi 传输，截图保存在电脑本地。

## 启动

需要 Node.js 22 或更新版本。打开项目目录，在 Git Bash 中运行：

```bash
npm ci
cp .env.example .env
```

第一次配置时，在 `.env` 里给 `TOKEN` 填一个自定的令牌，再运行 `npm start`。已有 `.env` 时跳过复制步骤。固定令牌后，重启服务也能继续用同一个快捷指令。

电脑用 [localhost:8787](http://localhost:8787) 打开白板，浏览器才能复制图片到剪贴板。终端会打印手机要用的上传地址和令牌。

## iPhone 配置

在「快捷指令」里新建「发到电脑」，添加三个动作：

1. **查找照片**。筛选相簿「屏幕快照」，按拍摄日期从新到旧排序，取最近 3 张。
2. **重复每一项**。输入选上一步找到的照片。
3. **获取 URL 内容**。把它拖到「重复每一项」和「结束重复」之间，按下表填写。

   | 设置 | 填写内容 |
   | --- | --- |
   | URL | 终端打印的手机上传地址，末尾是 `/api/upload` |
   | 方法 | `POST` |
   | 头部 | `X-Token`，值为终端打印的令牌 |
   | 请求体 | 选「文件」，文件变量选「重复项目」 |

如果 URL 栏自动填上了变量，删掉变量再粘贴地址。先手动运行一次并允许访问照片，确认白板收到截图。然后在 **设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下** 选「发到电脑」。也可以把同一个指令加到控制中心。

手机连不上时，检查两台设备是否在同一个 Wi-Fi，以及 Windows 防火墙是否允许 Node.js 使用专用网络。返回 `401` 时核对令牌。只收到一张或提示请求体为空时，检查上传动作的缩进和「文件 → 重复项目」。

## 白板操作

- **整理** · 滚轮缩放，拖空白处平移，拖图片调整位置，双击空白处添加文字卡。
- **复制** · 双击图片或选中后按 `Ctrl+C`。右键拖动可以框选，复制多张图时会按白板上的排布拼成一张 PNG。
- **清理** · 按 `Delete` 移除选中卡片，按 `Ctrl+Z` 撤销。「打开时清空」默认开启，重新打开白板会清掉卡片，同一标签页内刷新会保留。

## 数据存放

截图原图在 `data/images/`，白板布局和文字卡在 `data/board.json`。移除白板上的图片会保留原图。服务端按图片内容去重，所以手机每次传最近 3 张截图时，已经接收过的图会跳过。

项目使用 Node.js、Express 和 WebSocket，前端是静态 HTML、CSS 和 JavaScript，无需数据库或构建步骤。
